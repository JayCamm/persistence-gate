# Persistence Gate Core v1.4.2 — Canonical Status

Prepared July 29, 2026.

## Product definition

Persistence Gate is a provider-neutral evidence-control layer. It separates retrieval from influence and generation from release.

```text
source -> extraction -> source binding -> conservative normalization
       -> security quarantine -> evidence admission -> answer permission
       -> statement verification -> replayable decision trace
```

## Material improvements in v1.4.2

- Exact excerpt and source-coordinate preservation.
- Field-level confidence, status, basis, alternatives, and warnings.
- Explicit accept/review/reject candidate dispositions.
- Lifecycle, effective-date, scope, authority-class, and proposition normalization.
- Raw metadata cannot self-authorize a source as governing evidence.
- Improved handling of ambiguous dates, future-effective and expired material, contradictory state cues, and negated supersession language.
- A deterministic content-risk receptor that quarantines selected high-signal retrieved instructions, including common character-substitution variants.
- Correction/supersession, statement verification, and replay remain separate explicit controls.

## Current maturity

- Architecture: credible and modular.
- Deterministic kernel: strong in bounded rule fixtures.
- Synthetic normalization: strong within covered scenario families.
- Real-document source fidelity: validated on two clean PDFs.
- Independent real-document semantic understanding: not yet established.
- Live Microsoft tenant integration: deploy-ready source, not tenant-validated.
- Controlled pilot readiness: yes.
- Broad production readiness: no.
